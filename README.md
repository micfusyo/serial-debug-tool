# 網頁版串口調試工具 (Web Serial Debug Tool)

一個純前端、免安裝的串口調試工具，使用瀏覽器的 **Web Serial API** 直接連接串口設備，可進行數據收發、快捷指令發送與 Modbus RTU 操作。

## 專案說明

- 單一 HTML 檔案，無需後端伺服器、無需編譯、無需安裝任何套件。
- 使用瀏覽器 Web Serial API 與設備通訊（需要 Chrome / Edge 89+）。
- 支援明暗雙主題，可記憶使用者偏好。
- 資料儲存（快捷文字、主題）皆使用 `localStorage`，不會上傳任何資料。

## 系統需求

| 項目 | 需求 |
| --- | --- |
| 瀏覽器 | Chrome 或 Edge 89+（Firefox / Safari 不支援 Web Serial API） |
| 連線方式 | `localhost` 或 HTTPS 頁面（Web Serial API 的安全限制） |
| 設備 | 任何支援標準串口（CDC-ACM / UART）的裝置 |

## 操作方法

### 1. 啟動與連接

1. 直接以瀏覽器開啟 `debugtools8.html`（若在本機開發，可用 `python3 -m http.server` 後開啟 `http://localhost:8000/debugtools8.html`）。
2. 選擇**鮑率**（9600 ~ 4000000，預設 115200）。
3. 點擊「**連接設備**」，在彈出的視窗中選取要連接的串口裝置。
4. 按鈕顯示「已連接」即代表連線成功。

### 2. 數據收發

- **接收數據**：顯示設備回傳的資料，可切換「文本」或「16進位」顯示格式。
- **發送數據**：輸入要發送的內容，可切換「文本」或「16進位」格式；勾選「自動換行」會在發送時自動附加 `\r\n`。
- 點擊「**發送**」送出資料。

### 3. 工具按鈕（位於頂部控制列）

- **清空全部**：清空接收與發送文字框。
- **儲存接收數據**：將目前接收框的內容存成文字檔（檔名含時間戳記，如 `serial_receive_20260807_114530.txt`）。
- **發送檔案文本**：選擇一個文字檔，將其內容**逐行發送**（跳過空行，行間間隔 50ms，遵循「自動換行」設定）。

### 4. 快捷發送（右側面板）

提供三頁快捷按鈕，共 **F1 ~ F90**：

| 頁籤 | 按鈕範圍 |
| --- | --- |
| 快捷發送#1 | F1 ~ F30 |
| 快捷發送#2 | F31 ~ F60 |
| 快捷發送#3 | F61 ~ F90 |

- 在每列輸入框填入文字，點擊對應按鈕即可發送（自動附加換行與否遵循「自動換行」設定）。
- 輸入的文字會自動存入瀏覽器 `localStorage`，重新開啟頁面後依然保留。
- **保存快捷文字**：將 F1 ~ F90 全部內容存成 `quick_send_texts.json`。
- **讀取快捷文字**：從 JSON 檔載入 F1 ~ F90 內容並寫回輸入框與 localStorage。

### 5. Modbus RTU 操作

- **從站地址**：1 ~ 247。
- **功能碼**：01 讀取線圈、02 讀取離散輸入、03 讀取保持寄存器、04 讀取輸入寄存器、05 寫入單個線圈、06 寫入單個寄存器、15 寫入多個線圈、16 寫入多個寄存器。
- **起始地址 / 數量 / 數據值**：依功能碼填入；多筆數據以逗號分隔（如 `1,2,3`）。
- 點擊「**發送 Modbus 命令**」會自動計算 **CRC16** 並送出，同時將指令以 16 進位顯示在接收框中。

## 注意事項

- 儲存的接收數據與快捷文字僅存在本機瀏覽器，刪除瀏覽器資料即會消失。
- Web Serial API 僅在安全的上下文（localhost / HTTPS）中可用，部署至 GitHub Pages 等靜態託管時請使用 HTTPS。
